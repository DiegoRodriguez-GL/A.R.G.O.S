ARGOS

Agent Risk Governance and Operational Security. A security audit framework for AI agents built on the Model Context Protocol: static scanning, red teaming, a transparent audit proxy and compliance-mapped reports, from one CLI, without sending anything to the cloud.

Four ways to look at an agent

Each one produces the same finding shape, with evidence and compliance references.

Static scanner

argos scan reads Claude Desktop, VS Code and mcp-spec configurations and flags secrets, dangerous shell and Docker patterns, unpinned supply chain, tool poisoning and over-broad filesystem access.

Red teaming

argos redteam sends single- and multi-turn probes to an HTTP agent endpoint and classifies replies with string, regex, behaviour and optional LLM-judge detectors.

Audit proxy

argos proxy run sits between client and server over stdio, TCP, streamable-HTTP or SSE, detects tool drift, PII and out-of-scope calls, emits OpenTelemetry spans and keeps a SQLite trail.

In-process callback

A LangChain / LangGraph callback handler routes tool calls that never touch the wire through the same detector chain.

Evaluation lab

argos eval runs six deterministic agents against every probe and reports a confusion matrix with Wilson intervals, pinned as a regression test.

Reports

argos report renders a self-contained HTML file with a cross-framework compliance matrix, strict CSP and secrets redacted by default.

Principles

CLI-first

The terminal is the primary surface. Reports are static files.

Local-only

No cloud, no SaaS, no telemetry unless you point it at your own collector.

Zero-trust LLM

The model is treated as a potentially hostile user.

Verifiable

Every prompt, response and tool call is logged and tied to evidence.
